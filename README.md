Geospatial Flood Susceptibility Analysis and Web GIS Application
📌 Project Overview
This project presents a comprehensive Flood Susceptibility Analysis using multi-source satellite data, GIS techniques, and web-based visualization. The workflow integrates remote sensing datasets, geospatial processing, susceptibility modeling, and interactive Web GIS development to support flood risk assessment and decision-making.

The final output is an interactive web application that enables users to explore flood susceptibility zones through a user-friendly interface.

🎯 Objectives
Analyze flood-prone areas using multi-satellite datasets.
Generate flood susceptibility maps using geospatial techniques.
Integrate remote sensing and GIS-based factors influencing flood occurrence.
Develop an interactive Web GIS platform for visualization and analysis.
Facilitate flood risk awareness and decision support.
🛰️ Data Sources
The analysis utilizes multiple satellite and geospatial datasets, including:

Digital Elevation Models (DEM)
Land Use/Land Cover (LULC)
Rainfall Data
Slope and Aspect
Drainage Density
Distance from Rivers
Soil Data
Vegetation Indices
Other relevant remote sensing and environmental datasets
🛠️ Methodology
1. Data Acquisition
Multi-source satellite and ancillary datasets were collected from publicly available geospatial repositories.

2. Data Preprocessing
The datasets were processed and standardized using QGIS, including:

Projection and coordinate system correction
Raster clipping and masking
Data cleaning and normalization
Extraction of thematic layers
3. Flood Susceptibility Mapping
Several flood conditioning factors were generated and analyzed to identify flood-prone regions.

4. GIS Analysis
Spatial analysis and map preparation were carried out using:

QGIS for preprocessing and analysis
ArcMap for cartographic visualization and final map generation
5. Web GIS Development
The final flood susceptibility maps were integrated into a Python-based Web GIS system.

Features include:

Interactive map visualization
Layer control
Zoom and navigation tools
Popup information windows
Responsive user interface
Dynamic geospatial data display
